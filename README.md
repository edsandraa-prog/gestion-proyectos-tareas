# Sistema de Gestión de Proyectos y Tareas

## Descripción
Aplicación web desarrollada con Django para registrar,
organizar y administrar proyectos y tareas.

## Funcionalidades
- Registrar proyectos.
- Visualizar proyectos.
- Consultar detalles de cada proyecto.
- Registrar tareas.
- Editar y eliminar tareas.
- Marcar tareas como terminadas o pendientes.
- Visualizar estadísticas mediante gráficos.

## Tecnologías utilizadas
- Python
- Django
- HTML
- CSS
- Bootstrap 5
- JavaScript
- Apache ECharts
- SQLite

## Instalación

1. Clonar el repositorio.
2. Crear un entorno virtual.
3. Instalar las dependencias:

   pip install -r requirements.txt

4. Ejecutar las migraciones:

   python manage.py migrate

5. Iniciar el servidor:

   python manage.py runserver

6. Abrir en el navegador:

   http://127.0.0.1:8000/
